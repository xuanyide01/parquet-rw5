# 0.1.5 · 标题背景与包体优化

- 标题 Logo 由 238×86 缩小到 214×77，保持原图和位置，减少对人物面部的遮挡。
- 正常完成梨乃或翼的 AFTER STORY 时，立即切换为对应标题背景并保存选择；再次完成已通关的后日谈也会切换。章节回顾不会解锁或自动切换。之后仍可在 System 手动选择已解锁背景，重启保留选择。
- System 为选中卡片增加明亮边框与角标，并显示“使用中”“当前：某某背景”和切换提示。列表键包含选中、解锁状态，防止 Vela 复用旧卡片而不刷新高亮。
- 安装包 9,898,785 字节（9.90 MB），上限恢复为 10,000,000 字节。背景/CG 从原始素材重新压缩至 320×216 范围、JPEG 质量 62，保留完整画幅；没有二次压缩旧 JPEG。全部 1,013 项立绘、1,023 个身体/表情文件及通话特写与 0.1.4 逐字节一致。

31 项回归通过。正式包在官方通用 Vela 环境检查安装、Logo、设置反馈和服务生画面；两条后日谈自动背景与解锁后的选框刷新另用独立 QA 包和明确标注的终点测试存档验证，测试数据不进入正式包。记录见 `reports/native-v015/`。本版于 2026-10-30 获用户验收通过。
